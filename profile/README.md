## Robotics. AI. Automation.

A small engineering team in Zagreb working across robotics, AI, industrial automation and cloud infrastructure. We connect software to the systems, machines and processes it needs to work with.

### What we work on

**Robotics & perception**

ROS / ROS2, computer vision, mechatronics and robotic integration.

**AI systems**

Private AI assistants, operator copilots and reasoning grounded in system capabilities.

**Automation - DevOps**

Automation, system integration, edge and cloud infrastructure, CI/CD and observability.

### How we work

Start with a concrete problem. Build a small prototype. Measure what works. Develop the integration from there. Customer engineering and R&D inform each other.
